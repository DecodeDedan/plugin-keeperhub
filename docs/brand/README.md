# Brand

The mark is the product in four strokes: a request arrives (the dot), travels (the solid line),
meets the gate (the amber bar), and continues only as intent (the dashed line) until a human
approves. It is drawn on the same palette as the docs, the site and the launch video, so the
three read as one system.

| File | Use |
|---|---|
| `mark.svg` | the icon on light backgrounds |
| `mark-dark.svg` | the icon on dark backgrounds |
| `favicon.svg` | simplified for 16-32px, where the dashes would disappear |
| `icon-192.png`, `icon-512.png`, `icon-1024.png` | app icons, avatars, submission forms |
| `lockup.svg`, `lockup.png` | icon with the wordmark and the line |
| `social-preview.png` | 1280x640, for GitHub Settings -> Social preview |

Colours: ink `#18211d`, paper `#fdfdfb`, ledger `#eef1ea`, gate `#b0810f` (`#d9a520` on dark),
verified `#15683a`. Type: IBM Plex Mono 600 for the wordmark, IBM Plex Sans for supporting text.

Do not recolour the gate bar. It is the only element carrying meaning that the shape alone
does not: it is the thing that stops the transaction.
